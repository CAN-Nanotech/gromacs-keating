# GROMACS — <Extension Name>

This repository contains a research extension to GROMACS
developed by Selva Nair <selva.nair@utoronto.ca>

It implements Keating potential and includes InAs-water forcefield
as described in: Lucy Su et. al., Applied Surface Science (submitted).

## Status

This is a research version based on GROMACS 2025.2.
It is not the official GROMACS distribution.
